# Real pw.x output, Cr2Se2As PBE+U

Produced by Quantum ESPRESSO 7.2 on 2026-09-19: the group's Cr2Se2As
structure, PBE+U (Dudarev, U = 3.0 eV on both Cr sublattices), USPP,
Grimme-D3, converged scf (`conv_thr = 1e-10`) followed by a `bands` run on a
56-point circle at k_z = 0.25 b3, generated by `bands_input`.

- `the Fermi energy is 8.1169 eV` and `total magnetization = 0.00 Bohr
  mag/cell` -- the compensated altermagnetic state, not an accidental
  ferromagnetic one, and E_F matches the group's Wannier model
  (`evaluate_report.txt`: E_F = 8.1169 eV) to the digit.
- Committed specifically because reading it back exposed two bugs in
  `hubbard_is_active`/`require_hubbard` that no synthetic test had found:
  `Hubbard_U` in the XML is in **Hartree** (`1.102479665269648E-01` for a
  card asking for `3.0` eV -- `0.1102479665269648 * HARTREE_EV = 3.0`), and
  QE writes one `Hubbard_U` element per **species**, both labelled `"3d"`
  (`specie="CrU"` and `specie="CrD"`), which a label-only key collapses onto
  each other.

## Update: harmwave.x rerun on the 152-point circle (2026-09-20)

The original harmwave.x cross-check (harmwave_report.txt) used the earlier
56-point circle. `harmwave_report_152.txt` (in tests/data/harmwave_cr2seas/)
reruns the same tool on the group's best data -- the 152-point circle, band
44, lmax=45 -- so the Fortran and Python routes are now cross-checked on the
final dataset rather than an earlier one. Coefficient agreement: 5.1e-15 eV
max deviation across all 46 coefficients, machine precision.
