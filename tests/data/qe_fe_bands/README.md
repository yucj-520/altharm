# Real pw.x output, bcc iron

Produced by Quantum ESPRESSO 7.2 on 2026-09-19, and committed because the QE
reader has no other way to be checked against a file QE actually wrote.

- `scf.in` — LSDA scf, 8x8x8 grid, ONCV Fe, 80 Ry, `conv_thr = 1e-10`.
  Converged in 16 iterations to E_F = 18.1457 eV and 2.33 Bohr mag/cell, which
  is the right moment for bcc Fe.
- `bands.in` — generated by `altharm.qe.writer.bands_input` from a 24-point
  circle of radius 0.40 (2 pi / alat) in the k_x k_y plane.
- `bands.out` — the text output. Its printed eigenvalues are the *independent*
  reference: they come from a different code path inside QE than the XML, and
  the test parses them with its own regex rather than with anything in altharm.
- `data-file-schema.xml` — what `altharm.qe.reader.read_bands` reads.

The text output rounds eigenvalues to four decimals, so agreement better than
5e-5 eV is the most this comparison can show, and is what it shows.
